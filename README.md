# Adivinhador de Números

Um jogo simples de adivinhação de números feito com HTML, CSS e JavaScript.

## 🎯 Objetivo
O jogador deve adivinhar um número secreto gerado aleatoriamente dentro de um intervalo definido. Ele receberá dicas se o palpite está alto ou baixo até acertar o número.

## 🛠 Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## 🚀 Como Jogar
1. O jogo gerará um número aleatório dentro do intervalo definido.
2. O jogador insere um palpite no campo de entrada.
3. O jogo fornece dicas se o número está alto ou baixo.
4. O jogo termina quando o jogador acerta o número.

## 📂 Como Executar
1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/Adivinhe_o_numero.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Adivinhe_o_numero
   ```
3. Abra o arquivo `index.html` no navegador.
